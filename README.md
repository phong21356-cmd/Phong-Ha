
## Trình chỉnh giao diện kiểu Figma

Chạy `npm run dev` rồi mở `http://localhost:3000/editor.html`. Editor mở file `public/assets/aistudio/index_2a6addc9.html`:
chọn phần tử (canvas hoặc cây lớp), kéo để di chuyển, kéo ô vuông để đổi kích thước, nhấp đúp sửa chữ,
chỉnh chữ/màu/bo góc/khoảng cách ở bảng thuộc tính, Ctrl+Z hoàn tác, **Xuất HTML** để tải file đã sửa
(đặt cạnh `building.webp`). Nút "Mở file HTML…" cho phép mở file khác.
